# Oficina / TV room

Página estática: plano, alzado, cortes y render 3D (three.js desde CDN).

## GitHub Pages
1. Sube `index.html` y `.nojekyll` a la raíz de un repo.
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.
3. En 1–2 min queda en `https://<usuario>.github.io/<repo>/`.

Para actualizar, reemplaza `index.html` y haz push.
